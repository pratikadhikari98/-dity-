# प्रतीक अधिकारी (Pratik Adhikari) वेबसाइट

Static HTML/CSS/JS वेबसाइट — कुनै build step चाहिँदैन।

- `index.html` — गृहपृष्ठ
- `about.html` — पुरानो लिंकका लागि मात्र; index.html#view=about मा पठाउँछ
- `news.html` — (गृहपृष्ठको समाचार भागमा पुनर्निर्देशन)
- `book.html` — (गृहपृष्ठको किताब भागमा पुनर्निर्देशन)
- `admin.html` — Showcase admin (GitHub मा commit गर्ने)
- `data/` — shlokas, news, showcase आदि JSON
- `photos/`, `fonts/`, `flipbook/` — assets
