Token ब्राउजरमै (localStorage) save हुन्छ, कहीं पठाइँदैन — GitHub लाई बाहेक। यो browser अरूसँग share नगर्नुहोस्।

Zip बाट Website Update

अपडेट गरिएको website को zip यहाँ छान्नुहोस्। यसले GitHub को अहिलेको फाइलसँग तुलना गरी कुन फाइल नयाँ / परिवर्तन / हटाइने हो देखाउँछ — Commit तपाईंले छानेपछि मात्र हुन्छ। GitHub को "repo-main.zip" को माथिल्लो folder आफैं हटाइन्छ।
⚠ चिन्ह भएका फाइल (zip मा नभएका, वा Admin बाट बदलिने data/ / news/ का परिवर्तन) सुरुमा छानिएका हुँदैनन् — "हेर्नुहोस्" थिचेर फरक हेरेर मात्र छान्नुहोस्।
